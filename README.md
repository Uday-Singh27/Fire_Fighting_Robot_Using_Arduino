# Fire_Fighting_Robot_Using_Arduino

An automated, cost-effective fire detection and extinguishing system built using Arduino. This robot is designed to detect fire and suppress it without any human intervention,
improving safety and response time in hazardous environments.

Project Overview

This project focuses on developing an Arduino-based autonomous robot capable of:

Detecting fire using flame sensors
Navigating toward the fire source
Extinguishing fire using a water pump system

The system provides a fast, reliable, and low-cost solution for early fire control in homes, industries, and sensitive areas.

Objectives
To design an intelligent fire detection system
To automate fire extinguishing without human involvement
To reduce risk to human life in dangerous environments
To provide a low-cost alternative to traditional fire-fighting systems

How It Works
Flame Detection
Flame sensors detect infrared radiation emitted by fire
Signal Processing
Arduino processes the sensor data and determines fire direction
Robot Movement
Motor driver controls the robot to move toward the fire
Fire Extinguishing
Water pump activates and sprays water to suppress flames


Components Used
Arduino Uno (ATmega328P)
Flame Sensors (3 units)
L298N Motor Driver
DC Motors
Servo Motor (for nozzle control)
Water Pump
Relay Module
Battery (7.4V & 9V)
Chassis and Wheels

System Architecture
Input
Flame sensors (multi-directional detection)
Processing
Arduino Uno (decision-making & control logic)
Output
Motor driver (movement)
Relay module (pump activation)
Servo motor (water direction control)
